# SENZA.X Website (Astro + Decap CMS)

Bilingual (EN/ZH) website for SENZA.X custom furniture studio with Decap CMS backend.

## Tech Stack

- **Framework**: Astro 5
- **CMS**: Decap CMS (admin at `/admin`)
- **i18n**: Built-in Astro i18n (EN/ZH)
- **Content**: Markdown-based content collections
- **Deploy**: Vercel

## Development

```bash
npm install
npm run dev    # local dev at localhost:4321
npm run build  # production build to dist/
```

## Admin

Access the CMS admin panel at `/admin` after configuring GitHub OAuth.
